# HOOKAHBASE

Матрица вкусов табака для кальяна — удобный каталог для работы в заведении.

## Возможности

- Поиск по вкусу, бренду, названию
- Фильтры: категория, бренд, крепость
- Виды: список, матрица (вкус × крепость), по брендам
- Светлый спокойный интерфейс

## Стек

Статический сайт (HTML / CSS / JS), данные в `data.json`.

## Deploy

Репозиторий подключается к Vercel — деплой при пуше в `main`.
